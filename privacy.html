Privacy Policy

Last updated: July 30, 2026

This policy covers spicyvtubers.com and the "Spicy VTubers" browser extension for Chrome and Firefox.

The browser extension

The extension shows a small popup with the live spicyvtubers.com site and a toolbar badge indicating how many new creators have been added since you last checked. It does not have accounts, logins, forms, or any way to identify you personally.

What the extension stores

The extension keeps a small amount of data using the browser's built-in local storage (storage.local), on your device only:

  • The last known creator count
  • The timestamp of the last check
  • The badge number currently displayed

This data never leaves your device — it is not transmitted to us, sold, or shared with any third party.

Network requests the extension makes

When the popup is opened, and at most once per hour, the extension fetches spicyvtubers.com/data.json — a small public file containing only a total creator count and a timestamp. No cookies, identifiers, or personal data are attached to this request. The popup also loads spicyvtubers.com itself in an embedded frame, which is subject to the website practices described below.

What the extension does not do

  • No analytics or tracking scripts
  • No advertising
  • No collection of browsing history, form data, or personal information
  • No remote/third-party code — the extension only runs the code included in its published package

The website

spicyvtubers.com is a static, fan-made index of publicly available creator profiles. It has no accounts or logins, and does not use tracking or advertising cookies. Our hosting and CDN providers (e.g. Cloudflare) may process standard connection/server logs (such as IP address and request timing) as part of normal infrastructure operation, the same as with any website.

Changes to this policy

If this policy changes, the "Last updated" date above will be revised.
